# Employee Training and Certification Tracker - Phase 1

This Java console application is the Week 1 foundation for the SDC330 course project. It demonstrates user interaction, inheritance, composition, an interface, an abstract class, and polymorphism.

## Source files

- `App.java` - console interface and sample application data
- `Reportable.java` - reporting interface
- `TrainingRequirement.java` - abstract base class
- `Course.java` - derived training-course class
- `Certification.java` - derived certification class
- `Employee.java` - employee class composed of training requirements

## Run in VS Code

1. Open the project folder in VS Code.
2. Open `src/App.java`.
3. Select **Run Java**.
4. Enter `1`, `2`, or `3` at the menu prompt.
